CC-MF rectangle / differential_drive / maze: 5 trial 진단
실행일: 2026-10-29 (KST)

핵심 결론
단일 SQP_RTI가 log-Cholesky covariance dynamics의 접선을 따라 각속도 부호
반전을 불확실성 감소로 예측하고, 다음 제어 주기의 정확한 covariance 재전파가
이를 되돌리는 반복이 관측되었다. 이 과정이 작은 전후진과 좌우 회전의 limit
cycle을 만드는 주요 메커니즘이다. 별도의 수정/A-B 주행은 수행하지 않았으므로
이 메커니즘 제거가 모든 정지를 해결하는지는 후속 검증이 필요하다.

실험 조건
- cc_mf, rectangle 0.15 x 0.12 m, DD, maze, A*.
- seed 0-4, true 시작 pose perturbation: x/y std 0.02 m, heading std 0.05 rad,
  +/-3 sigma 제한, initial whole-footprint clearance >=0.01 m.
- trial당 최대 simulation 60 s, dt 0.1 s, horizon 20 (2 s).
- localization error off; animation/기존 plot 생성 off.
- stuck 판정: 최근 4 s endpoint 순변위 <=0.03 m; 연속 solver 실패 20회.
- 제어기 파라미터는 현재 Python 기본값. debug_mf/debug_infeasibility만 활성화.
- 5 trial 순차 실행. torch threads 6, CUDA/acados는 기존 pp 환경 사용.
- diagnostics와 JSON 저장은 solve() 시간 밖에서 수행한다. 이 실행의 latency를
  정상 운영 controller latency benchmark로 해석하지 않는다.
- 기존 controller/config 파일 변경 없음. source_hashes.json과 종료 시 파일 해시 일치.

정지 구간에서도 작은 병진과 회전이 계속되어 완전한 zero-input 정지와 구분된다.

직접 관측한 반복 메커니즘
1. 이전 주기의 retained control로 covariance를 정확히 재전파하여 nominal을 만든다.
2. 이 nominal에서 log covariance 전이와 MF 위험행을 한 번 선형화한다.
3. omega^2, |v*omega|에 의한 uncertainty 증가를 접선으로 근사하므로, 이전 omega와
   반대 부호의 입력이 매우 작은 covariance를 만드는 것처럼 보일 수 있다.
4. 한 번의 RTI 결과를 적용한다. 다음 주기의 재전파가 작은 covariance 예측을
   수정하면 접선의 방향도 바뀌고 반대 방향 회전이 다시 선택된다.

18.7 s의 heading sigma는 약 10.5배 과소예측된다. omega 변화량은 +/-0.35 rad/s로
alpha_max=3.5 rad/s^2, dt=0.1 s의 제한에 도달한다. 정확한 omega^2의 값은 부호를
바꾸어도 작아지지 않지만, 현재 부호에서의 접선은 반대 방향을 작게 예측한다.

저장된 모델로 재구성한 접선과 solver stage1 covariance의 차이는 위 세 주기에서
최대 4.42e-16이고, 전체 성공 1684주기에서도 최대 1.14e-12이다. 따라서 이 오차가
단일 RTI의 접선 결과라는 것을 직접 재현했다. 다음 주기 nominal sigma는 retained
입력과 저장된 source로 재구성한 값이며, 직접 저장한 nominal covariance는 아니다.

Trial 2 마지막 4초의 stage1 heading sigma 과소예측 중앙값은 5.33배이고,
Trial 3/4/5는 각각 6.69/5.96/6.92배이다. 같은 구간의 covariance log dynamics
오차 중앙값은 각각 2.04/2.09/2.03/2.23이다. 반면 성공 Trial 1의 마지막 4초에는
각속도 sign flip이 없고 covariance 오차 중앙값은 0.00135로 줄어든다.

Trial 2 마지막 4초의 첫 스텝 physical XY dynamics 오차는 중앙값 0.0065 mm,
최대 0.0153 mm이다. 기록된 NLP equality residual은 전체 주기에서 직접 계산한
covariance dynamics 최대 오차와 일치한다. 큰 잔차의 중심은 covariance이다.

위험 및 거리의 비선형 오차
- 성공 solver 1684회 중 1120회(66.5%)에서 예측 horizon의 exact PSDF가 음수였다.
  같은 모든 성공 주기의 affine hard guard는 tolerance 1e-6 이내에서 만족했다.
- 독립 점검에서 성공 1355회는 affine MF+slack을 만족한 active row가 동일 slack의
  fresh nonlinear MF 재평가에서 quantile residual -0.001 미만으로 바뀌었다.
- Trial 2, 18.6 s, stage12의 MF probability sum은 solver covariance를 넣으면
  0.09256이지만, pose를 고정하고 covariance만 정확히 전파하면 0.30765로 증가해
  epsilon=0.2를 넘는다. 이것은 MF 모델의 위험 합이며 실측 충돌확률이 아니다.
- MF 활성행은 주기당 평균 4.36-4.71개 바뀐다. geometry/활성행 전환도 surrogate
  변화를 증폭한다. 다만 Trial 3의 마지막 반복은 활성행이 20개로 일정한 시점에도
  지속되어 mask 전환만으로 설명되지는 않는다.

solver status=0은 이번 로그에서 비선형 문제의 수렴/feasibility를 보장하지 않았다.
정확한 covariance 전파 및 nonlinear 제약 검증 없이 RTI 결과를 바로 적용하는
현재 lifecycle이 이 차이를 허용한다.

배제하거나 구분한 설명
- 실패 Trial 2/4/5의 모든 solver status는 0이다. Trial 3만 status4 fallback이
  21.2 s와 35.5 s에 각 1회 있다. 모든 종료 직전 4초는 solver가 계속 성공했다.
- 실패 Trial 2/3/4/5의 종료 직전 4초 동안 reference slice index는 각각 5/13/7/5로
  변하지 않았다. 실제 순변위는 28.684/25.174/27.502/27.885 mm이다.
- Trial 2의 16.9-19.3 s 평균 |v|는 3.80 mm/s, 의미 있는 인접 omega 부호 반전은
  23회이다. Trial 3 마지막 2.5초는 omega=-0.17968/+0.17032가 매 스텝 교대한다.
- 저장된 precontrol pose 1686개에서 polygon 충돌은 없었다. 최소 polygon clearance는
  Trial별 0.544/0.405/0.600/0.977/0.527 mm이다. 첫 구간 PSDF substep도 음수가
  아니었다. 미래 horizon의 음수 PSDF를 실제 실행 충돌로 해석하지 않는다.

수정 우선순위 (이번 작업에서는 제어기 수정/추가 주행 없음)
1. covariance dynamics와 위험행을 제어 주기 내부에서 재선형화하고 nonlinear residual
   감소를 확인한다. SQP 반복, line search/trust region 등의 방법으로 접선 과신을 줄인다.
2. 적용 전 후보 입력의 정확한 covariance rollout과 nonlinear guard/MF residual을
   검사한다. 검증 실패 시 damping/재해석 등 명시적인 처리 정책을 둔다.
3. delta-omega 비용/추가 smoothing으로 제어 반전을 완화한다. 현재 비용은 omega^2만
   벌점(.01)이고 delta-omega 비용은 없다. smoothing만으로 비선형 예측 오류가
   해결되는지는 별도 검증이 필요하다.
4. 변경 후 같은 seed로 반복하여 목표도달, oscillation 횟수, nonlinear dynamics 잔차,
   실제 clearance를 함께 비교한다.
