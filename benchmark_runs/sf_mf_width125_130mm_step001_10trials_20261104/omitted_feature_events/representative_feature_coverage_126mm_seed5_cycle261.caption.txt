Probabilities are frozen local-model estimates using nominal feature geometry and each state's planning covariance; they are not measured collision rates. The MF value evaluates the unrelaxed affine row at the SF solution, using the same nominal state, without MF reoptimization. Negative actual signed PSDF indicates geometric overlap. This is one case, not a guarantee that MF would prevent the event. Feature identities are held fixed from the nominal state to the SF solution.
